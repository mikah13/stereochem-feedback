# Stereochem feedback

Bug reports and feature requests for [Stereochem](https://stereochem-orcin.vercel.app), a free molecule editor that runs in your browser.

This repository holds feedback only. The source code is kept elsewhere.

- [Report a bug](../../issues/new?template=bug_report.yml)
- [Suggest a feature](../../issues/new?template=feature_request.yml)
- No GitHub account? Use the [feedback form](https://tally.so/r/VLggjv).

Before you open an issue, search the [existing issues](../../issues) to see if someone has already reported it. If they have, add a thumbs-up reaction instead of a new issue. We use reactions to decide what to work on first.

The [editor guide](https://stereochem-orcin.vercel.app/docs) explains how each tool works.
